# TechBooks Store 📚

A modern **online book store** built with **React**, featuring dynamic book search, cart functionality, and Google OAuth authentication. Perfect for learning React, Firebase, and front-end development best practices.  

---

## 🚀 Features

- **Book Search:** Search for programming, AI, and tech books using Google Books API.  
- **Featured Slider:** Highlights trending books with smooth background transitions.  
- **Shopping Cart:** Add books to cart, view mini cart, and manage items.  
- **User Authentication:** Sign in with Google using Firebase Authentication.  
- **Responsive Design:** Works perfectly on desktop, tablet, and mobile.  
- **Smooth Animations:** Background slider, hover effects, and interactive UI elements.  
- **LocalStorage Caching:** Reduces API calls and improves loading speed 
- **Newsletter Subscription:** Subscribe to get updates on new books and offers.

## 🛠️ Technologies Used

- **Frontend:** React, React Router  
- **Authentication:** Firebase (Google OAuth)  
- **Styling:** SCSS, CSS Flexbox  
- **State Management:** React Context API (Cart Context)  
- **API Integration:** Google Books API  
- **Deployment:** Vercel
